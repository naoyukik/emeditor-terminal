# Specification: Gemini CLIによるセキュリティチェック

## 1. 概要 (Overview)
プロジェクトの品質と安全性を担保するため、Gemini CLI (`gemini-cli-security` 拡張) を用いた網羅的なセキュリティチェックを実施する。特に Win32 API を扱う Infrastructure レイヤーや外部入力処理における潜在的な脆弱性を特定し、対処する。

## 2. 対象範囲 (Scope)
- **スキャン対象**: プロジェクト全体のソースコード (`src/` 配下すべて)。
- **対象外**: コンパイル済みバイナリ、依存関係パッケージ本体 (スキャンツールがサポートしない場合)。

## 3. 要件 (Requirements)
1.  **スキャンの実行**: `/security:analyze` コマンドを使用して、プロジェクト全体のセキュリティスキャンを実行する。
2.  **重要度評価と修正**:
    -   検出された脆弱性の重要度 (Severity) を評価する。
    -   **High および Critical** レベルの脆弱性を必須修正対象とする。
    -   Low/Medium レベルの脆弱性については、可能であれば修正し、困難な場合はリスクとして記録・許容する。
3.  **検証と確認**:
    -   修正後、再度 `/security:analyze` を実行し、対象の脆弱性が解消されたことを確認する (自動再スキャン)。
    -   修正が既存機能に悪影響を与えていないか、`install.ps1` を用いて実機での動作確認を行う。
    -   修正内容がプロジェクトのレイヤードアーキテクチャ規約に反していないか検証する。

## 4. 完了条件 (Acceptance Criteria)
- [ ] `gemini-cli-security` によるスキャンが完了している。
- [ ] 検出された High / Critical レベルの脆弱性がすべて修正されている、もしくは許容可能なリスクとしてドキュメントに明記されている。
- [ ] 再スキャンにより、修正対象の脆弱性が検出されないことが確認されている。
- [ ] 実機動作確認で、ターミナル機能が正常に動作することが確認されている。
- [ ] アーキテクチャ規約の検証をパスしている。
