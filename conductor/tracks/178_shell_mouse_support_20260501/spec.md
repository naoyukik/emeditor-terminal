# 仕様書: シェル上でのマウス操作のサポート (Issue #178)

## 概要
本トラックでは、SGR 1006 マウストラッキングが無効な標準シェル（PowerShell や WSL など）に対するマウス操作のサポートを実装します。目的は、右クリックによる貼り付けや、プロンプト上での左クリックによるカーソル移動を可能にすることで、最新のターミナルに期待される操作性を提供することです。

## 機能要件
- **右クリックによる貼り付け**: ターミナルビュー内の任意の場所で右クリックすると、システムのクリップボードにあるテキストがアクティブなプロンプトに無条件で貼り付けられます。
- **左クリックによるカーソル移動**: 現在のカーソルと同じ行を左クリックした場合、現在のカーソル位置からクリックされた列までの水平距離を計算し、必要な回数分の「左（`\x1b[D`）」または「右（`\x1b[C`）」の矢印キーエスケープシーケンスを送信して、目的の列へカーソルを移動させます。
- **Shift キー修飾によるバイパス挙動**: Shift キーを押しながらクリックまたは右クリックした場合、EmEditor のネイティブ処理（標準のテキスト選択や右クリックメニュー表示など）を優先させるのではなく、Shift 修飾付きのターミナルエスケープシーケンスを直接ターミナルに送信します。
- **マウスドラッグによるテキスト選択**: マウスの左ボタンをドラッグすることで、ターミナル上のテキストを選択状態にできるようにします。
- **右クリックによる選択範囲のコピー**: テキスト選択範囲が存在する場合、ターミナル内の任意の場所を右クリックすると、その選択範囲のテキストがシステムクリップボードにコピーされます。
- **Ctrl+C による選択範囲のコピー**: テキスト選択範囲が存在する場合、Ctrl+C キー押下でその選択範囲のテキストをクリップボードにコピーします。選択範囲がない場合は、従来通り中断信号（Ctrl+C）をターミナルに送信します。
- **Ctrl+V による高速貼り付け**: Ctrl+V キー押下時、プラグイン側でクリップボードのテキストを直接取得してターミナルに送信します。これにより、TUI アプリケーション等における貼り付けの遅延を解消します。

## 非機能要件
- **互換性**: シミュレートされる入力（貼り付けおよび矢印キー）は、**PowerShell (`pwsh.exe` / `powershell.exe`)** および **WSL (`bash` / `zsh`)** において徹底的にテストされ、確実に動作する必要があります。
- **安定性**: カーソル移動のシミュレーションは水平方向（左右）に厳密に制限され、シェル履歴の予期せぬナビゲーション（上下キーによる誤動作）を防ぎます。

## 受け入れ基準 (Acceptance Criteria)
- [x] PowerShell または WSL で右クリックした際、直ちにクリップボードのテキストが貼り付けられること。
- [x] 入力行において、現在のアクティブなカーソルの左右をクリックした際、矢印キーのエスケープシーケンスが送信され、カーソルが正しく移動すること。
- [x] Shift キーを押しながらクリックした際、EmEditor のネイティブな選択やコンテキストメニューがトリガーされることなく、適切に変更されたイベントがターミナルへ送信されること。
- [ ] マウスの左ボタンをドラッグした際、ターミナル内のテキストが選択（反転表示）されること。
- [x] テキスト選択範囲が存在する状態で右クリックした際、選択範囲のテキストがクリップボードにコピーされること。
- [x] テキスト選択範囲が存在する状態で Ctrl+C を押下した際、選択範囲のテキストがクリップボードにコピーされること。
- [x] 選択範囲がない状態で Ctrl+C を押下した際は、ターミナルへ `\x03` が送信されること。
- [ ] Ctrl+V を押下した際、クリップボードのテキストが遅延なくターミナルに貼り付けられること。

## スコープ外 (Out of Scope)
- マウスクリックによる垂直方向のカーソル移動（上下矢印キーの送信）。
