# 仕様書 (Specification): vteの一括書き込み最適化 (Issue 103)

## 概要 (Overview)
`vte` クレートのパース処理のゼロコピー化特性を活かし、同一属性の連続する文字を一括で処理することで、レンダリングパイプラインの高速化を目指す。現在の1文字ずつの処理によるオーバーヘッドを解消する。また、Conductorのワークフローを改善し、トラック作成時に即座にブランチを作成するルールを明文化する。

## 機能要件 (Functional Requirements)
1. **バッファリングの導入**:
   - `TerminalProtocolHandler` にて `vte::Perform::print` の呼び出しをバッファリングし、属性が変わるか制御文字が来るまでテキストを蓄積する。
2. **一括書き込みメソッドの実装**:
   - 蓄積したテキストをスライスとして一括で `TerminalBufferEntity` へ書き込むメソッド（例: `print_string`）を導入する。
3. **ワークフローの更新 (Chore)**:
   - `conductor/workflow.md` に、トラック作成時にその名前で Git ブランチを作成する手順を追記する。
   - 実際に本トラック名でブランチを作成する。

## 非機能要件 (Non-Functional Requirements)
- **パフォーマンス**: 大量出力（`cat`コマンド等）時の CPU 負荷が低減されること。

## 受け入れ条件 (Acceptance Criteria)
- [ ] 大量のテキスト出力時において、描画とスクロールが従来より滑らかに動作すること。
- [ ] 結合文字や絵文字を含むテキストが、バッファリング導入後も既存の書記素クラスタ処理によって正しく描画されること。
- [ ] `conductor/workflow.md` が更新されていること。
- [ ] 本トラック専用のブランチが作成されていること。
